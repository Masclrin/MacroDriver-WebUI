# 已知缺陷与后期考虑

> 本文档为项目审查的权威参考。审查前请先查阅本文档和 `11-设计意图说明.md`，确认待审查问题是否已有定论。

## 1. 已知缺陷（未修复）

| 编号 | 问题 | 严重程度 | 说明 |
|------|------|---------|------|
| B-01 | `check_results` 无锁直接访问 | 低 | GIL 提供基本保护，加锁影响执行精度，实际触发概率极低 |
| B-02 | `_detect_cycle_dfs` visited 不清除 | 低 | 可能是有意设计，漏检场景极罕见 |
| B-03 | 序列化端口 key 回退到数字索引 | 低 | 仅在节点定义不可用时触发，正常流程不会出现 |
| B-04 | `TaskPool._propagate_stop` 子任务完成后空转 | 低 | daemon 线程不阻止退出，开销极小 |
| B-05 | `monitor_time` auto_stop=false 循环线程竞态 | 中 | 旧 wait_thread 未 join，建议使用 `loop_while + monitor` 组合替代 |
| B-06 | `join` 循环内 Event clear 竞态 | 中 | 不建议在循环内重复使用 join，文档说明最佳实践 |
| B-07 | `run_automation` 多变量无锁读写 | 低 | 快速重入场景极罕见，已有旧任务超时检测 |

## 2. 后期考虑

| 编号 | 问题 | 说明 |
|------|------|------|
| P-01 | `mouse_scroll` 缺坐标参数 | 用户可先移动再滚动 |
| P-02 | `string_op` concat 只能拼接两个 | 可链式使用 |
| P-03 | `preset_find_click` 无移动动画 | 防作弊是特殊场景 |
| P-04 | `join` target_fork_node_id nodeRef 不完善 | 基本功能可用 |
| P-05 | `call_script` path 缺 varRef | 脚本路径通常固定 |
| P-06 | Ctrl+D 只支持单节点复制 | Ctrl+C/V 已支持多选 |
| P-09 | 插件串行加载速度慢 | 当前插件量小，影响不大 |
| P-11 | `check_screen` region 缺 showWhen | 全屏默认值即可 |
| P-12 | `color` 字段不支持 varRef | 颜色变量引用需求极低 |
| P-13 | UndoManager 重复 push | 需梳理所有 push 调用点 |
| P-14 | `_graphDirty` undo/redo 后状态不正确 | 需精确追踪 dirty 状态 |
| P-15 | 拾取修改属性不触发撤销系统 | 需配合 UndoManager 重构 |
| P-16 | 多处 try-catch 静默吞掉错误 | 仅影响调试 |
| P-17 | 插件 backendAction 未存入注册表 | 第三方插件生态发展后再改 |
| P-18 | `鼠标点击`/`控制`/`监视器` handler 双重解析 | 当前幂等不影响功能 |
| P-19 | `property.js` 变量选择器 check_类节点 store_var 类型硬编码 | 架构优化，功能不受影响 |
| P-20 | `plugin_manager.py` reload 时注销所有插件节点 | 当前插件量少，影响有限 |
| P-21 | OCR 引擎单一（仅 PaddleOCR） | 后续版本会集成新引擎 |
| P-22 | `renderers.js` dpiScale 全局变量残留 | 4个 window 全局变量已不被核心渲染逻辑使用，清理需评估影响 |
| P-23 | `store_hwnd_var` screen 模式获取前台窗口可能不准 | screen 模式下点击可能改变前台窗口，是系统行为 |
| P-24 | 日志面板轮询间隔固定 1 秒 | 空闲时仍轮询，浪费资源，后期改为按执行状态动态调整 |
| P-25 | 日志面板条目上限 200 无用户提示 | 静默截断，后期添加"显示更多"提示 |
| P-26 | 节点搜索不搜索属性值 | 后期考虑添加属性值搜索选项 |
| P-27 | 工具箱拼音搜索依赖外部数据 | 插件节点无法通过拼音搜索，需动态生成拼音映射 |
| P-28 | `_syncNodeInlineField` 对 var_list 触发完整 DOM 刷新 | 可能导致焦点丢失，后期优化为局部更新 |
| P-29 | 变量选择器对 var_list 项的变量引用替换边界处理 | itemIndex 越界时静默失败，后期添加边界校验 |

## 3. 已拒绝（不再讨论）

| 编号 | 问题 | 拒绝理由 |
|------|------|---------|
| R-01 | `mouse_move_rel` 缺 easing 参数 | 短距离缓动不可感知，增加复杂度收益低 |
| R-02 | 单个动作节点入口选择逻辑 | 正确的设计行为 |
| R-03 | 动作节点添加数据输出端口 | 架构变更，需整体评估 |
| R-04 | `preset_find_click` 没有数据输出端口 | 预设节点定位是简化版，需完整数据输出用 check_image + mouse_click |
| R-05 | 插件 node.js 无沙箱 | 架构选择，插件需完整 JS 能力 |
| R-06 | 插件 onExecute 只在模拟执行时调用 | 设计选择，前端 onExecute 是调试/预览功能 |
| R-07 | 重命名不允许"未命名脚本" | 防止默认名称脚本混淆 |
| R-08 | loop_while+检测/goto+循环/监视器+fork 联动 | 复杂边界场景，修复核心问题后大部分可正常工作 |
| R-09 | `mouse_scroll` delta 不直观 | 已添加说明 |
| R-10 | `flow/end` 全局停止 | 设计意图 |
| R-11 | 监视器不响应暂停 | 监视器模型不允许 |
| R-12 | HTML 注入/XSS | 本地应用低风险 |
| R-13 | notify 弹窗阻塞 | 有意设计 |
| R-14 | `node.params` 并发修改线程安全 | executed_set 机制保证不存在并发修改 |
| R-15 | `InterceptionSession` 资源泄漏 | 全局单例懒加载，无显式释放需求 |
| R-16 | `_ensure_data_inputs` 深度调整 | 当前 100 上限足够 |
| R-17 | `setNextNodeId` Infinity 防御 | 正常流程不可能产生 Infinity ID |
| R-18 | `var_math` 除零返回 0 | 容错设计，记录错误日志但继续执行 |
| R-19 | `store_hwnd_var` screen 模式不准 | screen 模式下点击可能改变前台窗口，是系统行为 |
| R-20 | `call_script_sync` 文件不存在走 next | 容错设计，记录错误后继续执行 |
| R-21 | 变量选择器弹窗不显示内置变量 | 设计意图：太多变量导致选择困难，想使用可通过变量面板点击复制 |
| R-22 | 右键菜单粘贴节点重叠 | 粘贴始终在当前鼠标位置，不存在重叠问题 |
