# 全局参数与执行配置

## 1. 概述

全局参数是影响所有自动化脚本执行的系统级配置。用户通过前端全局参数页修改，存储在 `config/params.json` 中。

## 2. 参数层级

参数优先级（从高到低）：

```
节点参数 > 全局参数 > 系统默认值
```

- 节点参数：在节点属性面板中设置，仅影响该节点
- 全局参数：在全局参数页中设置，影响所有节点
- 系统默认值：代码中的硬编码默认值

当节点参数未设置（使用默认值）时，fallback 到全局参数。

## 3. 参数分类

### 3.1 执行器参数 (`executor`)

控制旧引擎（宏执行框架3.2）的行为：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `speed_factor` | number | 1.0 | 速度倍率（0.1~10.0） |
| `timeline_mode` | enum | absolute | absolute / relative |
| `random_delay` | bool | false | 是否启用随机延迟 |
| `random_delay_min` | number | 0 | 随机延迟最小值（ms） |
| `random_delay_max` | number | 50 | 随机延迟最大值（ms） |
| `low_cpu_mode` | bool | false | 低 CPU 模式 |
| `batch_send` | bool | false | 批量发送输入 |
| `test_trace` | bool | false | 测试追踪输出 |
| `lag_compensation` | bool | false | 延迟补偿 |
| `auto_release_modifiers` | bool | true | 自动释放修饰键 |

### 3.2 输入参数 (`input`)

控制按键和鼠标输入行为：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `key_press_delay` | number | 10 | 按键按下延迟（ms） |
| `key_release_delay` | number | 10 | 按键释放延迟（ms） |
| `mouse_click_delay` | number | 10 | 鼠标点击延迟（ms） |
| `mouse_move_speed` | number | 1.0 | 鼠标移动速度倍率 |
| `text_input_delay` | number | 10 | 文本输入字符间延迟（ms） |
| `scroll_delay` | number | 10 | 滚轮延迟（ms） |

### 3.3 检测参数 (`detection`)

控制检测子系统行为：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `capture_method` | enum | dxgi | dxgi / bitblt |
| `capture_fps` | number | 60 | 截图帧率 |
| `ocr_engine` | enum | default | default / paddle / tesseract |
| `ocr_language` | string | ch | 识别语言 |
| `image_match_method` | enum | tm_ccoeff_normed | 默认匹配算法 |
| `pyramid_levels` | number | 2 | 金字塔加速层级 |
| `frame_diff_threshold` | number | 5 | 帧差阈值 |

### 3.4 高级参数 (`advanced`)

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `process_priority` | enum | normal | normal / high / realtime |
| `thread_affinity` | bool | false | 是否启用线程绑核 |
| `affinity_cores` | string | "" | 绑核核心列表（逗号分隔） |
| `debug_mode` | bool | false | 调试模式 |
| `log_level` | enum | info | debug / info / warn / error |

## 4. 新引擎与旧引擎的参数传递

新引擎调用旧引擎时，传递以下 options：

```python
options = {
    "speed_factor": node.params.get("speed_factor", 1.0),
    "timeline_mode": node.params.get("timeline_mode", "absolute"),
    "random_delay": node.params.get("random_delay", False),
    "auto_release_modifiers": False,  # 新引擎自己管理
}
```

其余参数（low_cpu、batch_send、test_trace、lag_compensation 等）由旧引擎从全局变量中读取。

## 5. 执行档案 (Execution Profile)

通过 `graph.settings.execution_profile` 选择：

| 档案 | Interception 键盘 | Interception 鼠标 | 优先级提升 | 线程绑核 |
|------|-------------------|-------------------|------------|----------|
| `lite` | 否 | 否 | 否 | 否 |
| `standard` | 否 | 否 | 是 | 否 |
| `precision` | 是 | 是 | 是 | 是 |

### 5.1 Interception 驱动

- 内核级输入驱动，延迟低于 SendInput
- 需要安装 Interception 驱动
- 仅在 `precision` 档案下启用
- 键盘和鼠标可独立控制

### 5.2 进程优先级

- `standard` 和 `precision` 档案下提升进程优先级到 `HIGH_PRIORITY_CLASS`
- 执行结束后恢复

### 5.3 线程绑核

- `precision` 档案下启用
- 主线程绑定到核心 0
- 分支线程按 `branch_affinity_N` 参数绑定

## 6. 精确引擎参数

`engine/precision.py`（即 `precision_engine_v5.py`）提供：

| 功能 | 说明 |
|------|------|
| `precise_sleep_v5(seconds, stop_event)` | 高精度 sleep（0.1ms 级） |
| `set_thread_affinity(core_id)` | 设置线程绑核 |
| `clear_thread_affinity()` | 清除线程绑核 |
| `set_process_priority(priority)` | 设置进程优先级 |
| `restore_process_priority()` | 恢复进程优先级 |

精确引擎在 `standard` 和 `precision` 档案下自动初始化。
