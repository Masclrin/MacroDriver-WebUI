# 前端编辑器规范

## 1. 概述

前端是基于 HTML/JS 的可视化节点编辑器，运行在嵌入式浏览器（CEF/PyWebView）中。

## 2. 画布

### 2.1 新建画布

新建自动化脚本时，画布自动包含一个 `flow/start` 节点。用户从开始节点出发构建工作流。

### 2.2 节点操作

| 操作 | 方式 |
|------|------|
| 添加节点 | 从左侧节点面板拖拽到画布 |
| 移动节点 | 拖拽节点标题栏 |
| 删除节点 | 选中后按 Delete 键 |
| 复制节点 | Ctrl+C / Ctrl+V |
| 连线 | 从端口拖拽到目标端口 |
| 断开连线 | 右键连线 → 删除 |

### 2.3 画布交互

- 滚轮缩放
- 中键拖拽平移
- 右键菜单（复制/粘贴/删除/禁用）
- 节点选中高亮

## 3. 节点面板

### 3.1 分类组织

节点按 category 分组显示：
- 流程控制
- 动作
- 检测
- 监视器
- 控制
- 变量
- 工具
- 预设
- 插件（动态）

### 3.2 搜索

- 支持拼音搜索：输入 "bingfa" → 匹配 "并发执行"
- 支持中文搜索：输入 "点击" → 匹配 "鼠标点击"、"预设点击"、"找图点击"
- 支持英文搜索：输入 "click" → 匹配 "mouse_click"、"preset_click"
- 实时过滤，输入即搜

### 3.3 节点颜色

| 分类 | 颜色 |
|------|------|
| 流程控制 | 灰色 |
| 动作 | 蓝色 |
| 检测 | 绿色 |
| 监视器 | 橙色 |
| 控制 | 紫色 |
| 变量 | 青色 |
| 工具 | 黄色 |
| 预设 | 粉色 |
| 插件 | 自定义 |

## 4. 属性面板

### 4.1 动态表单

根据节点的 `params_schema` 动态生成表单控件：

| 参数类型 | 控件 |
|----------|------|
| `number` | 数字输入框（支持滑块） |
| `string` | 文本输入框 |
| `bool` | 开关/复选框 |
| `enum` | 下拉选择 |
| `color` | 颜色选择器 |
| `region` | 区域选择器（可视化选取） |
| `affinity` | 绑核设置面板 |
| `json` | JSON 编辑器 |

### 4.2 条件显示

`showWhen` 字段控制参数的条件显示：
```
showWhen: "mode=window"        → 仅当 mode 为 window 时显示
showWhen: "check_mode=change"  → 仅当 check_mode 为 change 时显示
```

### 4.3 变量引用

支持 `${变量名}` 语法的参数在输入框旁显示变量选择按钮，点击可浏览和选择已有变量。

### 4.4 坐标参数

坐标相关参数（`coordMode: true`）支持：
- 可视化选取（点击"选取"按钮后在屏幕上框选）
- 模式切换（screen/window/relative/current）
- 书签引用（`@书签名.x`）

## 5. 连线

### 5.1 流程连线

- 蓝色实线
- 从输出端口到输入端口
- 一个输出可连多个输入
- 一个输入可接收多个输出

### 5.2 数据连线

- 绿色虚线
- 从检测节点的结果端口到控制节点的条件端口
- 传递检测结果

### 5.3 连线验证

- 流程端口只能连流程端口
- 数据端口只能连数据端口
- 同类型端口间连线
- 无效连线显示红色提示

## 6. 工具栏

| 功能 | 说明 |
|------|------|
| 保存 | 保存为 `.auto.json` |
| 另存为 | 保存为新文件 |
| 运行 | 执行当前自动化脚本 |
| 停止 | 停止执行 |
| 暂停/继续 | 暂停/恢复执行 |
| 撤销/重做 | 操作历史 |
| 缩放 | 放大/缩小/适应画布 |
| 全局参数 | 打开全局参数设置页 |
| 变量管理 | 打开变量管理面板 |

## 7. 执行状态显示

### 7.1 节点状态

| 状态 | 显示 |
|------|------|
| 待执行 | 默认样式 |
| 执行中 | 黄色边框闪烁 |
| 已完成 | 绿色边框 |
| 出错 | 红色边框 + 错误图标 |

### 7.2 错误提示

- 执行出错时，前端以 Toast 弹窗显示错误信息
- 错误信息来自后端 `get_automation_status` 返回的 `errors` 字段
- 出错节点在画布上高亮显示

## 8. 全局参数页

独立页面，通过工具栏按钮打开。按 section 分组显示所有可调参数：

| Section | 标题 | 说明 |
|---------|------|------|
| `executor` | 执行器参数 | 旧引擎参数（speed_factor、timeline_mode 等） |
| `input` | 输入参数 | 按键/鼠标延迟、修饰键行为 |
| `detection` | 检测参数 | 截图方式、OCR 引擎 |
| `advanced` | 高级参数 | 绑核、优先级、调试 |

每个参数显示：标签、当前值、默认值、推荐值、说明、示例。
