# 宏驱动 自动化编辑器插件开发示例（精简版）

## 一、快速理解架构

- **后端**：Python 动态加载 `plugins/` 下各插件的 `backend.py`，引擎调用 `execute(action, params, context)`。
- **前端**：浏览器执行插件 `node.js`，通过 `window.__plugin_nodes__ = nodes` 注册节点到工具箱。
- **通信**：后端 `context.emit(event, data)` → 前端 `onPluginEvent(eventName, data)`。

## 四、node.js 核心定义

```javascript
var nodes = {
  'plugin/notify_popup': {
    display_name: '消息弹窗',
    color: '#a855f7',
    category: 'plugin',
    icon: 'fa-solid fa-bell',
    backendAction: 'notify_popup',       // 对应后端 action
    inputs:  [{name:'in', type:'flow'}], // 流程输入
    outputs: [{name:'next', type:'flow'}],// 流程输出

    params_schema: {
      title: {
        type: 'string',
        label: '标题',
        default: '提示',
        varRef: true          // 引擎自动解析 ${变量}
      },
      duration: {
        type: 'number',
        label: '时长(ms)',
        default: 3000,
        varRef: true
      }
    },

    onExecute: function(params) {
      // 仅模拟执行时触发
    },

    onPluginEvent: function(eventName, eventData) {
      if (eventName === 'notify_popup_shown') {
        // 处理
      }
    }
  }
};

window.__plugin_nodes__ = nodes;  // 必须导出
```

### 4.1 params_schema 支持的类型

| type | 控件 | 额外属性 |
|------|------|---------|
| `string` | 文本框 | `varRef`, `format: 'color'/'path'`, `browseType: 'folder'/'file'` |
| `number` | 数字框 | `min`, `max`, `step`, `varRef` |
| `enum` | 下拉 | `options: ['a','b']`, `varRef`, `coordMode: true` |
| `bool` | 开关 | — |
| `slider` | 滑块 | `min`, `max`, `step` |
| `region` | 坐标区域 | `coordMode: true`, `default: [x,y,w,h]` |

**通用属性**：`label`（必须）、`default`、`description`、`showWhen`（条件显示）

### 4.2 条件显示（showWhen）

```javascript
params_schema: {
  mode:     { type: 'enum', label: '模式', default: 'auto', options: ['auto', 'manual'] },
  threshold: { type: 'number', label: '阈值', default: 0.8, showWhen: 'mode=manual' },
  count:    { type: 'number', label: '数量', default: 1, min: 0, max: 5 },
  item_0:   { type: 'string', label: '项目1', default: '', showWhen: 'count>=1' },
  item_1:   { type: 'string', label: '项目2', default: '', showWhen: 'count>=2' }
}
```

支持 `=`、`!=`、`>=`、`<=`、`>`、`<`，逗号分隔多条件（AND），同字段连续段（OR）。

### 4.3 输出端口扩展

```javascript
outputs: [
  { name: 'next', type: 'flow' },
  { name: 'timeout', type: 'flow' },  // 自定义出口，通过 flow_port 指定
  { name: 'success', type: 'flow' },  // {"ok": true} 走此分支
  { name: 'fail', type: 'flow' },     // {"ok": false} 走此分支
  { name: 'result', type: 'data' }    // 接收 check_results["result"]
]
```

### 4.4 坐标模式参数（截图/检测插件必备）

```javascript
params_schema: {
  mode:     { type: 'enum', label: '坐标模式', default: 'screen',
              options: ['screen', 'window', 'relative'], coordMode: true },
  rect:     { type: 'region', label: '检测区域', default: [0,0,0,0], coordMode: true },
  hwnd_var: { type: 'string', label: '窗口变量', default: '', varRef: true,
              description: 'window/relative模式需要指定窗口句柄变量名' }
}
```

- `coordMode: true` → 自动获得坐标拾取/框选按钮，参数归入「坐标」分组
- `varRef: true` → 引擎自动解析 `${变量}` 引用

## 五、backend.py 核心实现

### 5.1 varRef 自动解析

当 `params_schema` 中设置了 `varRef: true` 时，**引擎会自动解析** `${变量}` 引用：

```python
def execute(action, params, context):
    title = params.get("title")  # 已经是解析后的值，无需手动处理
    duration = params.get("duration", 3000)  # 同上
```

**未设置 `varRef: true` 的参数保持原始字符串，需手动解析（见第六节）。**

### 5.2 返回值规范

```python
{"ok": True}                                                     # 成功
{"ok": True, "check_results": {"result": True, "confidence": 0.95}}  # 数据端口
{"ok": True, "set_variables": {"http_status": 200}}              # 设置变量
{"ok": True, "flow_port": "timeout", "check_results": {...}}     # 自定义出口
{"ok": False, "error": "原因"}                                   # 失败
```

> `flow_port` 可指定走哪个自定义输出端口（如 `timeout`），优先级高于 ok/success/fail/next。

**flow_port 完整示例**：

```javascript
// node.js — 定义多个 flow 输出端口
outputs: [
  {name:'next', type:'flow'},       // 正常完成
  {name:'timeout', type:'flow'},    // 超时
  {name:'fail', type:'flow'}        // 失败
]
```

```python
# backend.py — 通过 flow_port 指定出口
def execute(action, params, context):
    if idle_timed_out:
        return {"ok": True, "flow_port": "timeout", "check_results": {"count": 5}}
    if error_occurred:
        return {"ok": False, "error": "原因"}  # 走 fail 端口
    return {"ok": True, "check_results": {"count": 5}}  # 走 next 端口
```

**路由优先级**：
1. 返回值包含 `flow_port` 且节点定义了该端口 → 走指定端口
2. `flow_port` 指定的端口不存在 → 回退到 `next`
3. 无 `flow_port` → 按 `ok: true/false` → `success/fail/next` 逻辑

### 5.3 坐标模式后端模板（截图插件必备）

```python
def _get_hwnd(params, context):
    hwnd_val = params.get("hwnd_var", "")
    if not hwnd_val:
        return None
    try:
        return int(hwnd_val)
    except (ValueError, TypeError):
        pass
    if isinstance(hwnd_val, str) and hwnd_val.startswith("${") and hwnd_val.endswith("}"):
        var_name = hwnd_val[2:-1]
        val = context.get_variable(var_name, "")
        if val:
            try:
                return int(val)
            except (ValueError, TypeError):
                pass
    val = context.get_variable(str(hwnd_val), "")
    if val:
        try:
            return int(val)
        except (ValueError, TypeError):
            pass
    return None

def _resolve_region(mode, rect, hwnd=None):
    try:
        from engine.coordinate import resolve_region
        return resolve_region(mode, rect, hwnd)
    except Exception:
        return tuple(int(v) for v in rect)

def execute(action, params, context):
    mode = params.get("mode", "screen")
    hwnd = _get_hwnd(params, context)
    rect = params.get("rect", [0, 0, 0, 0])
    phys_region = _resolve_region(mode, rect, hwnd)
    frame = context.capture_screen(list(phys_region))
    # ...
```

**坐标存储约定**：
- **screen**：存储物理像素坐标（所见即所得），`resolve_region` 直通
- **window**：存储窗口内逻辑偏移（不含 DPI 缩放），`resolve_region` 运行时加窗口原点并乘 DPI
- **relative**：存储 0~1 比例值，`resolve_region` 运行时乘窗口物理尺寸加原点偏移

**坐标全链路**：
```
拾取器(tools.js)  → 物理像素 / dpiScale = 逻辑坐标 → 写入属性
属性面板(renderers.js) → window模式: 逻辑坐标 * dpiScale = 物理像素 → 显示给用户
后端(coordinate.py) → resolve_region: 逻辑坐标 * dpiScale + 窗口原点 = 物理坐标 → capture_screen
```

### 5.4 context 对象

| 方法 | 说明 |
|------|------|
| `context.emit(event, data)` | 推向前端 |
| `context.log(level, msg)` | 写日志（debug/info/warning/error） |
| `context.capture_screen([x,y,w,h])` | 截图（物理像素坐标），返回 numpy BGR。自动回退链：DXGI → BitBlt → mss |
| `context.get_screen_size()` | → `{"width":1920,"height":1080}` |
| `context.get_variable(name, default)` | 读流程变量 |
| `context.set_variable(name, value)` | 写流程变量（跨插件共享） |
| `context.find_window(title, class_name)` | 返回 hwnd |
| `context.get_window_rect(hwnd)` | → `{"x","y","width","height"}` |
| `context.show_desktop_popup(...)` | 桌面置顶弹窗 |
| `context.play_sound(...)` | 播放音频 |
| `context.precise_sleep(seconds)` | 高精度等待（替代 time.sleep），自动响应停止/暂停，返回 True/False |
| `context.get_mouse_position()` / `set_mouse_position(x,y)` | 鼠标位置 |
| `context.find_image(template, region, threshold)` | 图像模板匹配 |
| `context.check_color(x, y, color, tolerance)` | 单点颜色检测 |

## 六、变量解析（未设 varRef 时需手动解析）

参数中的 `${变量}` **只有在 `varRef: true` 时才会被引擎自动替换**。未设 varRef 的参数需手动解析：

```python
import re, time

_BUILTIN = {
    "timestamp": lambda: str(int(time.time()*1000)),
    "date": lambda: time.strftime("%Y-%m-%d"),
    "time": lambda: time.strftime("%H:%M:%S"),
    "datetime": lambda: time.strftime("%Y-%m-%d %H:%M:%S"),
    "random_int": lambda: str(__import__('random').randint(0,999999)),
}

def resolve_vars(value, context):
    if not isinstance(value, str):
        return value
    pattern = re.compile(r'\$\{([^}]+)\}')
    matches = pattern.findall(value)
    if not matches:
        return value
    if len(matches)==1 and value==f"${{{matches[0]}}}":
        return _resolve_single(matches[0], context)
    result = value
    for var_name in matches:
        result = result.replace(f"${{{var_name}}}", str(_resolve_single(var_name, context)))
    try:
        if result.replace('.','',1).replace('-','').isdigit():
            num = float(result)
            return int(num) if num==int(num) else num
    except: pass
    return result

def _resolve_single(var_name, context):
    if var_name in _BUILTIN:
        return _BUILTIN[var_name]()
    val = context.get_variable(var_name)
    if val is not None:
        return _fmt_num(val)
    if '.' in var_name:
        cr_val = context.get_check_result(var_name)
        if cr_val is not None:
            return _fmt_num(cr_val)
        graph = context.get_graph()
        if graph:
            try:
                for nid, node in graph.nodes.items():
                    if node.type=="utility/bookmark" and node.params.get("name")==node_id:
                        return node.params.get(port,"")
            except: pass
    cr_val = context.get_check_result(var_name)
    if cr_val is not None:
        return _fmt_num(cr_val)
    return ""

def _fmt_num(v):
    if isinstance(v, float) and v==int(v):
        return int(v)
    return v
```

## 七、前后端通信模式速查

| 场景 | 实现 |
|------|------|
| **纯前端操作** | `onExecute` 里直接调用 `alert / Audio` 等 |
| **纯后端任务** | `backend.py` 完成计算，返回 `{"ok":True}` |
| **后端异步 + 前端反馈** | `backend.py` 开线程，`context.emit("done", data)`，前端 `onPluginEvent` 监听 |
| **前端主动调后端** | `window.pywebview.api.call_plugin(plugin_id, action, params)` |

## 八、完整迷你示例：Hello 插件

**manifest.json**
```json
{"id":"hello","name":"Hello","nodes":["say"],"icon":"fa-hand","color":"#10b981"}
```

**node.js**
```js
var nodes = {
  'plugin/say': {
    display_name:'打招呼', color:'#10b981', icon:'fa-hand',
    backendAction:'say',
    inputs:[{name:'in',type:'flow'}],
    outputs:[{name:'next',type:'flow'}],
    params_schema: {
      name: {type:'string', label:'名字', default:'世界', varRef:true}
    },
    onPluginEvent: function(ev, data) {
      if(ev=='said') alert(data.message);
    }
  }
};
window.__plugin_nodes__ = nodes;
```

**backend.py**
```python
def register(): return [{"action":"say","name":"打招呼"}]
def execute(action, params, context):
    name = params.get("name", "世界")  # varRef=true，引擎已自动解析
    msg = f"你好，{name}！"
    context.emit("said", {"message":msg})
    context.log("info", msg)
    return {"ok":True}
```
